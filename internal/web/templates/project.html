Create a project

A name and a repository URL. That provisions a sandbox, clones the repo, and checks out the doot branch. There is no other setup step.

Public and private both work. The GitHub token from Settings is installed in the sandbox as a git credential, so clone, fetch, and push all use native git over HTTPS. An SSH-style git@github.com:owner/repo URL is rewritten to HTTPS.

One project at a time

Enforced by a unique index in Postgres, not a check in the UI. To work on something else, delete this project and create another — the conversation and tool history of the old one stay readable in History.

Conversation

Clearing archives every message and starts the context fresh. It does not touch the sandbox: the repo, branch, working tree, and anything running all survive.

Archived messages stay readable in History. Unavailable while doot is running.

Sandbox recovery

In increasing order of destructiveness. Try them in that order.

Destroys the sandbox and provisions a new one, re-cloning the repo. Uncommitted work is lost.

Destroys the sandbox and clears the project. Conversation, goals, and tool history are kept and stay readable in History.
