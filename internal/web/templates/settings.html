Create a project

A name and a repository URL. That provisions a sandbox, clones the repo, and checks out the doot branch. There is no other setup step.

Public and private both work. The GitHub token above is installed in the sandbox as a git credential, so clone, fetch, and push all use native git over HTTPS. An SSH-style git@github.com:owner/repo URL is rewritten to HTTPS.

One project at a time, enforced by a unique index in Postgres rather than a check in the UI. To work on something else, delete the current one first.
